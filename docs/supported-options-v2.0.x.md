#### Supported options for v2.0.x

| Flag                                   | Env variable           | Default value                                    | Description                                                                                                                                              |
|----------------------------------------|------------------------|--------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--opentelekomcloud-access-key`        | `OS_ACCESS_KEY`        |                                                  | Access key for AK/SK auth                                                                                                                                |
| `--opentelekomcloud-secret-key`        | `OS_SECRET_KEY`        |                                                  | Secret key for AK/SK auth                                                                                                                                |
| `--opentelekomcloud-auth-url`          | `OS_AUTH_URL`          | https://iam.eu-de.opentelekomcloud.t-systems.com | Authentication URL                                                                                                                                       |
| `--opentelekomcloud-availability-zone` | `OS_AVAILABILITY_ZONE` | eu-de-03                                         | Availability zone                                                                                                                                        |
| `--opentelekomcloud-cloud`             | `OS_CLOUD`             |                                                  | Name of cloud in [`clouds.yaml`](https://docs.openstack.org/python-openstackclient/latest/configuration/index.html) file. AK/SK can be set in this file. |
| `--opentelekomcloud-cacert`            | `OS_CACERT`            |                                                  | CA certificate bundle to verify against                                                                                                                  |
| `--opentelekomcloud-domain-id`         | `OS_DOMAIN_ID`         |                                                  | OpenTelekomCloud Domain ID                                                                                                                               |
| `--opentelekomcloud-domain-name`       | `OS_DOMAIN_NAME`       |                                                  | OpenTelekomCloud Domain name                                                                                                                             |
| `--opentelekomcloud-eip`               | `OS_EIP`               |                                                  | Elastic IP to use                                                                                                                                        |
| `--opentelekomcloud-eip-type`          | `OS_EIP_TYPE`          | 5_bgp                                            | Bandwidth type (either `5_bgp` or `5_mailbgp`)                                                                                                           |
| `--opentelekomcloud-endpoint-type`     | `OS_INTERFACE`         | public                                           | Endpoint type                                                                                                                                            |
| `--opentelekomcloud-flavor-id`         | `OS_FLAVOR_ID`         |                                                  | Flavor id to use for the instance                                                                                                                        |
| `--opentelekomcloud-flavor-name`       | `OS_FLAVOR_NAME`       | s2.large.2                                       | Flavor name to use for the instance                                                                                                                      |
| `--opentelekomcloud-bandwidth-size`    | `OS_BANDWIDTH_SIZE`    | 100 (MBit/s)                                     | Bandwidth size                                                                                                                                           |
| `--opentelekomcloud-bandwidth-type`    | `OS_BANDWIDTH_TYPE`    | PER (exclusive bandwidth)                        | Bandwidth share type                                                                                                                                     |
| `--opentelekomcloud-image-id`          | `OS_IMAGE_ID`          |                                                  | Image ID to use for the instance                                                                                                                         |
| `--opentelekomcloud-image-name`        | `OS_IMAGE_NAME`        | Standard_Ubuntu_24.04_amd64_uefi_latest          | Image name to use for the instance                                                                                                                       |
| `--opentelekomcloud-ip-version`        | `OS_IP_VERSION`        | 4                                                | Version of IP address assigned for the machine (only 4 is supported by opentelekomcloud for now)                                                         |
| `--opentelekomcloud-keypair-name`      | `OS_KEYPAIR_NAME`      |                                                  | Key pair to use to SSH to the instance                                                                                                                   |
| `--opentelekomcloud-password`          | `OS_PASSWORD`          |                                                  | OpenTelekomCloud Password                                                                                                                                |
| `--opentelekomcloud-private-key-file`  | `OS_PRIVATE_KEY_FILE`  |                                                  | Private key file to use for SSH (absolute path)                                                                                                          |
| `--opentelekomcloud-project-id`        | `OS_PROJECT_ID`        |                                                  | OpenTelekomCloud Project ID                                                                                                                              |
| `--opentelekomcloud-project-name`      | `OS_PROJECT_NAME`      |                                                  | OpenTelekomCloud Project name                                                                                                                            |
| `--opentelekomcloud-region`            | `OS_REGION`            | eu-de                                            | Region name                                                                                                                                              |
| `--opentelekomcloud-root-volume-size`  | `OS_ROOT_VOLUME_SIZE`  | 40                                               | Set volume size of root partition (in GB)                                                                                                                |
| `--opentelekomcloud-root-volume-type`  | `OS_ROOT_VOLUME_TYPE`  | SSD                                              | Set volume type of root partition (one of `SAS`, `SSD`)                                                                                                  |
| `--opentelekomcloud-sec-groups`        | `OS_SECURITY_GROUP`    |                                                  | Existing security groups to use, separated by comma                                                                                                      |
| `--opentelekomcloud-server-group`      | `OS_SERVER_GROUP`      |                                                  | Define server group where server will be created                                                                                                         |
| `--opentelekomcloud-server-group-id`   | `OS_SERVER_GROUP_ID`   |                                                  | Define server group where server will be created by ID                                                                                                   |
| `--opentelekomcloud-skip-default-sg`   |                        |                                                  | Don't create default security group                                                                                                                      |
| `--opentelekomcloud-skip-eip`          |                        |                                                  | If set, elastic IP won't be created, machine IP will be set to instance local IP                                                                         |
| `--opentelekomcloud-ssh-port`          | `OS_SSH_PORT`          | 22                                               | Machine SSH port                                                                                                                                         |
| `--opentelekomcloud-ssh-allow-cidr`    | `OS_SSH_ALLOW_CIDR`    | 0.0.0.0/0                                        | CIDR allowed to reach the SSH port in the default security group                                                                                         |
| `--opentelekomcloud-ssh-user`          | `OS_SSH_USER`          | ubuntu                                           | SSH user                                                                                                                                                 |
| `--opentelekomcloud-subnet-id`         | `OS_SUBNET_ID`         |                                                  | Subnet ID the machine will be connected on                                                                                                               |
| `--opentelekomcloud-subnet-name`       | `OS_SUBNET_NAME`       | subnet-docker-machine                            | Subnet name the machine will be connected on                                                                                                             |
| `--opentelekomcloud-token`             | `OS_TOKEN`             |                                                  | Authorization token                                                                                                                                      |
| `--opentelekomcloud-tags`              | `OS_TAGS`              |                                                  | Comma-separated list of instance tags (e.g. key1.value1,key2.value2,key3)                                                                                |
| `--opentelekomcloud-user-data-file`    | `OS_USER_DATA_FILE`    |                                                  | File containing an userdata script                                                                                                                       |
| `--opentelekomcloud-user-data-raw`     |                        |                                                  | Contents of user data file as a string                                                                                                                   |
| `--opentelekomcloud-username`          | `OS_USERNAME`          |                                                  | OpenTelekomCloud username                                                                                                                                |
| `--opentelekomcloud-vpc-id`            | `OS_VPC_ID`            |                                                  | VPC ID the machine will be connected on                                                                                                                  |
| `--opentelekomcloud-vpc-name`          | `OS_VPC_NAME`          | vpc-docker-machine                               | VPC name the machine will be connected on                                                                                                                |
